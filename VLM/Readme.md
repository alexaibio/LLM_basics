# Explaining Visual Language Models (VLM) with paligemma as an example
PaliGemma is a family of lightweight, open VLMs (Google) that take both images and text as input to generate text outputs. 
Inspired by PaLI-3, it pairs a SigLIP vision encoder with a Gemma language model decoder.
It is designed primarily to be fine-tuned for specific downstream vision-language tasks.

References:
- visual transformer - https://arxiv.org/pdf/2010.11929
- visual encoder (SigLIP) - https://arxiv.org/abs/2502.14786
- video - https://www.youtube.com/watch?v=vAmKB7iPkWw
- github - https://github.com/hkproj/pytorch-paligemma
